Внимание: антивирус может ругаться

Перед скачиванием ExclusionLauncher v2.4.1 — прочитайте, пожалуйста.

Этот лаунчер модифицирует процесс Minecraft и использует DLL-инъекцию для встраивания функционала клиентов. Из-за этого Windows Defender, Kaspersky, Avast и другие антивирусы могут ложно среагировать на файл — выдать предупреждение или удалить его.

Это ложноположительная детекция, типичная для любых программ, которые внедряются в чужой процесс. Сам файл не содержит вредоносного кода, если скачан с официального сайта.

  1. 1
    Добавьте папку лаунчера в исключения
    В Windows Defender: Защита от вирусов → Управление настройками → Исключения. Так файлы не будут удаляться автоматически.
  2. 2
    Если браузер блокирует скачивание
    Нажмите «Сохранить в любом случае» или «Продолжить» — это известное предупреждение для неизвестных издателей.
  3. 3
    Скачивайте только с официального сайта
    Не используйте сторонние «зеркала» и файлообменники — только так можно гарантировать оригинальный файл.
